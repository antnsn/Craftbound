# Commands

`/craftbound` works everywhere `/craft` does.

| Command | What it does |
| --- | --- |
| `/craft` | Opens or closes the [Craftbound window](features/window.md): every guide, where to stop and what it costs, your own guides. |
| `/craft tracker` | Shows or hides the tracker. |
| `/craft guide` | Opens the Craftbound window to pick a guide. |
| `/craft guide enchanting` | Makes the Enchanting guide the active one (`alchemy` likewise). |
| `/craft stop 150` | Stops the active guide at 150 (or `225`, `300`; `end` for the guide's end). |
| `/craft list` | Prints what the rest of the route still needs in chat. |
| `/craft tick` | Ticks off the current step. `/craft tick 3` ticks off step 3. |
| `/craft untick 3` | Puts step 3 back on the list. |
| `/craft reset` | Forgets this character's progress in the active guide. |
| `/craft toggle panel` | Turns the profession window panel on or off. |
| `/craft toggle shop` | Turns the auction house panel on or off. |
| `/craft toggle select` | Turns selecting the step's recipe on or off. |
| `/craft toggle tracker` | Turns the tracker on or off. |
| `/craft toggle minimap` | Shows or hides the minimap button. |
| `/craft toggle cap` | Turns off (or on) the question before Blizzard's Create buttons craft at a rank's cap. |
| `/craft help` | Lists the commands in chat. |
